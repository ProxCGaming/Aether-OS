### Fixed
- **[2026-11-14] Silent WS dispatch drop closed and the three unheard engine pushes wired (master build S2)**: (1) the receive loop's dispatch lookup had no `else` — a message that parses as a valid `EventType` but has no `_DISPATCH` entry (shell/engine version skew) got no reply and no log, so the UI would hang waiting; it now answers `ERROR` naming the type (with the request id) and logs a warning, exactly like the parse-level failures. (4) `VOICE_RTC_ICE_RESPONSE` is now heard: a refusal for the live voice session mirrors the offer-refusal path and flips voice to its error state instead of leaving a live-looking overlay behind a failed negotiation; `ok: true` is a pure acknowledgement (the engine's own candidates arrive as `VOICE_RTC_ICE` pushes).
